# تاريخ الجولات والإصلاحات

> مستخرج من README الأصلي لتسهيل الصيانة — المصدر الوحيد للحقيقة هو الكود.

## جولة الإغلاق: حدود خطأ · صفحات معلّقة · جودة كود

| ما كان                                                                                                  | ما صار الآن                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| خطأ تصيير في مسار يُفرَّغ `#main` بلا رسالة                                                             | `ErrorBoundary` حول المسارات: شاشة استرجاع (`role="alert"` + إعادة محاولة + رسالة الخطأ الحقيقية في `details`)، والشريط والتذييل والثيم واللغة تبقى حيّة. ومفتاح الحدود يتغيّر مع المسار فتُنظَّف الحالة تلقائيًا                                                                                                                          |
| `listOrders` و`verifyKey` مكتوبتان ولا يُستدعيان                                                        | مساران حقيقيان: `/track` (إيصالات بالبريد، يقبل `?email=`) و`/licence` (تحقّق من مفتاح، يقبل `?key=`) — يعملان محليًا وعبر `rest` بنفس العقد                                                                                                                                                                                               |
| لا ESLint ولا Prettier ولا CI                                                                           | `eslint.config.js` (eslint 10 + `eslint-plugin-react-hooks`) و`.prettierrc.json`؛ `lint` و`format:check` نظيفان تمامًا، و`.github/workflows/ci.yml` يشغّل lint → format → test → build على كل دفع                                                                                                                                          |
| بطاقة مشاركة واحدة لكل المنتجات                                                                         | `public/og/<slug>.png` لكل منتج (١٥ بطاقة 1200×630 بلون القالب وموك يتبع نوعه)؛ `Seo.jsx` يبدّل `og:image` و`twitter:image` وصورة JSON-LD لكل قالب، وتبقى بطاقة الموقع الافتراضية في `index.html` للمستكشفات التي لا تشغّل JS                                                                                                              |
| لا `LICENSE` ولا حقل ترخيص                                                                              | `LICENSE` (MIT لكود المتجر فقط، مع استثناء صريح لمنتجات القوالب والعلامة التجارية) + `license` و`engines` في `package.json`                                                                                                                                                                                                                |
| تصدير `Skeleton` بلا مستخدم                                                                             | مستخدم فعلًا في حالة تحميل `/track` — لا تصدير معلّق في `src/` الآن                                                                                                                                                                                                                                                                        |
| شريط «منصّات يعمل عليها عملاؤنا» يتحرّك ويقفز                                                           | صار **صفًّا ثابتًا**: أُزيلت `--animate-marquee` والـ keyframes من `index.css`، وبلا نسخة مكرّرة (`ul > li` بعشر عناصر، لا عشرون) — القفز كان من `translateX(-50%)` مع `gap` بين النسختين. ومع `prefers-reduced-motion: reduce` تُوقَف الحركة فعليًا الآن: أضفنا `animation-iteration-count: 1` لأن تسريع المدة وحده كان يبقيها تدور للأبد |
| شارة «درجة الأداء/ATS» تظهر **خلف** معاينة القالب في الرئيسية                                           | بطاقات المروحة تحمل `zIndex` صريحًا (٤→١) والشريحتان الطافيتان كانتا `auto` ⇒ صارتا `z-[10]`. الفحص يقرأ `style.zIndex` الحقيقية للبطاقات ويقارنها، فلا يتعطّل لو كبرت المروحة                                                                                                                                                             |
| نموذج «النشرة» كان يقول «تم الاشتراك» ولا يُرسل شيئًا                                                   | صار صادقًا: العنوان يُحفظ في `qalb.newsletter.v1` على الجهاز فقط، ويظهر زر `mailto:` مُعبّأ يصل الاستوديو فعلًا، مع سطر يشرح أنه لا توجد خدمة رسائل موصولة بعد (نفس معيار «الدفع مُحاكى»)                                                                                                                                                  |
| `SITE_URL` كان مقروءًا في `scripts/seo.mjs` ولا أحد يعرف به                                             | موثَّق في `.env.example`، و`seo.mjs` و`server/worker.js` يقرآن `.env` الآن (node لا يقرأه وحدَه)، فـ `PORT` والمفاتيح والنطاق كلها من ملف واحد                                                                                                                                                                                             |
| بريد الدعم منسوخ في ٤ ملفات (الرئيسية، صفحة القالب، الإيصال، التذييل)                                   | مصدر واحد `src/data/contact.js` يقرأ `VITE_QALB_MAIL`، وفحص في `npm test` يرفض أي نسخة حرفية بعده                                                                                                                                                                                                                                          |
| الوكيلُ الآلي (GPTBot وClaudeBot وPerplexityBot…) لا يجدُ تصريحًا صريحًا ولا نصًّا يقرأه بلا JavaScript | `scripts/agents.mjs` يولّد `public/robots.txt` بكتلةِ سماحٍ لكلِّ وكيلٍ ومنعٍ واحدٍ للجميع، و`public/llms.txt` ملخّصًا ثنائيَّ اللغةِ أرقامُه مقروءةٌ من `src/data/*` — و`prebuild` يُشغّلها قبل كلِّ بناء، والفحصُ يقارن القرصَ بالمولّد سطرًا بسطر                                                                                       |
| رمز Apple الخاص (U+F8FF) في شارات الدفع                                                                 | صار `Apple Pay` نصًا، والشرائح الرسومية (`mc`, `apple`) أخذت `role="img" + aria-label + title` — الرمز الخاص كان سيظهر مربّعًا على أي نظام غير macOS، والشارحة بلا اسم تقرأها القارئ الآلي الآن                                                                                                                                            |

| ٢٩ ملف woff2 مودَعة بلا نص ترخيص | `public/fonts/OFL-*.txt` الثلاثة منسوخة حرفيًا من مصادرها + `public/fonts/README.md` يوثّق العائلة والمصدر (OFL تُلزم بإبقاء النص مع الخط) |

| محمّل `.env` مكرور في `seo.mjs` و`worker.js` | وحدة واحدة `scripts/dotenv.mjs` يستوردها الاثنان، مع فحص في `npm test` يرفض رجوع النسخة المكرورة |

اصطادت القواعد الجديدة أخطاء حقيقية، وأُصلحت في مصدرها لا بالتسكين: `setState` داخل effect في شريط
التنقل والكتالوج (صارت المزامنة أثناء الرندر، وحجم الصفحة مشتقًّا من مفتاح الفلاتر بلا جولة رسم زائدة)،
ومكوّنان كانا يُولَّدان داخل الرندر (`Contacts` في `ResumePreview` و`ProjectCard` في `SitePreview` —
صارتا دالَّتَي رسم بنفس الشجرة وهوية ثابتة)، و`flags` صارت مثبَّتة بـ`useMemo`، وستّة `catch {}` صارت موثّقة.

## تشذيب هذه الجولة (إصلاحات لا تجميل)

| المشكلة                               | الحل                                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| حزمة واحدة 401 kB لكل المسارات        | `React.lazy` لكل مسار + `<Suspense>` بهيكل تحميل — الأصلي 308 kB وبقية الصفحات 13 حزمة صغيرة                  |
| المعاينة تختفي في حاوية بعرض 0        | `scale = w ? w/dev.w : 1` بدل هيكل تحميل أبدي — المحتوى موجود دائمًا في DOM                                   |
| معاينة المواقع كانت `dir="ltr"` دائمة | `Site()` تستقبل `rtl` وتضبط `dir` (مع عزل اتجاه رابط الموقع)                                                  |
| Enter لا ينقل بين خطوات الدفع         | الخطوة `<form onSubmit>` وزر «متابعة» `type="submit"` + `inputMode/enterKeyHint/autoComplete` للبطاقة والجوال |
| أخطاء الحقول بلا ربط                  | `aria-invalid` + `aria-describedby` + `role="alert"` (الدفع وكود الخصم)                                       |
| مفتاح الترخيص يقول «تم النسخ» دائمًا  | Clipboard API مكشوف الفشل: رسالة صريحة عند المنع + تنزيل ملف `.txt`                                           |
| نافذة المعاينة تسرّب التركيز          | `createPortal` إلى `body` + `inert`/`aria-hidden` على `#root` + مصيدة Tab واسترجاع التركيز                    |
| «شاهدتها مؤخرًا» معرّفة وغير مستخدمة  | `pushRecent` يُنادى من صفحة المنتج، والشريط يظهر في الرئيسية والكتالوج                                        |
| عنوان/وصف ثابت لكل المسارات           | `Seo.jsx` يحدّث `title` و`description` و`og:`/`twitter:` لكل مسار                                             |
| ToastAdd خاطئ تحت StrictMode          | `add()` يقرأ `lines` مباشرة ويعيد هل العنصر جديد                                                              |
| نصوص منسوخة في الكود                  | `cart.couponRemoved` · `success.copyFail` · `wishlist.count` · `featured.recent*`                             |
| `Btn` داخل `<form>` يرسل النموذج      | `type="button"` افتراضيًا عند عدم وجود `to`                                                                   |
