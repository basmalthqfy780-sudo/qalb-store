# لوحة الإدارة

> مستخرج من README الأصلي لتسهيل الصيانة — المصدر الوحيد للحقيقة هو الكود.

## لوحة الإدارة (Admin)

تُفتح من `/admin`، ومن عمود «الشركة» في التذييل (رابط «لوحة الإدارة» — `footer.admin`، ظاهرٌ لكل زائر بقرارٍ معلن؛
الحمايةُ كلمةُ السرّ لا الإخفاء). فيها أربعة أقسام:
**النظرة العامة** (دخل، عدد الطلبات الناجحة، متوسط السلة، ضريبة ١٥٪ المستخرجة، آخر ٣٠ يومًا، الأكثر مبيعًا)،
**المنتجات** (تصفير السعر، ربط رابط التنزيل — عام أو `/download/<id>` محمي، إخفاء/إظهار، منتج مخصّص جديد، تعديل النصوص والفئة)،
**الطلبات** (مع تصدير CSV حقيقي من بيانات الطلبات نفسها)، و**الصلاحيات** (إضافة مسؤول، تغيير كلمة سر، حذف — مع رفض حذف الحساب الموثّق حاليًا أو آخر مالك).

| النقطة                                                | السلوك الفعلي                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| من أين تأتي الأرقام                                   | لا شيء مكتوب يدويًا: الدخل والطلبات تُحسب من سجلّ الطلبات نفسه (`src/data/stats.js`) — `qalb.orders.v1` في الوضع المحلي، و`server/orders.jsonl` في وضع الخادم. نفس الوحدة يستوردها الخادم، فلا يوجد حسابان مختلفان.                                                                                                                                                                                                                                                                                                             |
| سعر الأكثر مبيعًا                                     | كل سطر طلب يُختم عليه السعر الذي حوسب فعلًا، فيبقى إيراد المنتج ما دُفع وقت البيع لا سعر اليوم؛ وتجمع أعمدة «الأكثر مبيعًا» فيساوي الدخل الإجمالي. الطلبات الأقدم من هذه القاعدة تُحسب بالسعر الحالي، نصًا.                                                                                                                                                                                                                                                                                                                     |
| نصّ «أضف إلى السلة» و«اشتراك» كان يختفي فوق زرّ فاتح  | قواعد الـ reset في `src/index.css` كانت مكتوبة **خارج `@layer`**، و`button { color: inherit }` و`* { border-color }` كانت تتغلّبان على كل أداة Tailwind (طبقات CSS تُحسم قبل الـ specificity). صارتا داخل `@layer base`: الاسم ظهر، و`border-brand/40` و`focus:border-brand/50` و٣٦ عنوانًا بـ`font-extrabold` تعمل كما كُتبت. فحص `css · cascade layers` يرفض أي عنصر بلا طبقة يلوّن النص، ويقيس تباين WCAG فعلًا: dark 6.7–16.4 وlight 5.1–17.8 على أسطحها، مع تصحيح حبر الوضع الفاتح إلى `#04140d` بدل أبيض 3.4:1 على الأخضر |
| تعديل المنتجات = طبقة فوق المصدر                      | `src/data/templates.js` **لا يُعاد كتابته أبدًا**. التعديلات تُخزَّن كتجاوزات (overrides) وتُدمَج وقت التشغيل عبر `src/data/catalog.js`، فيبقى المستودع نظيفًا والرجوع ممكنًا بحذف ملف التجاوزات.                                                                                                                                                                                                                                                                                                                               |
| الحذف = إخفاء                                         | الزرّ يخفي المنتج (`published:false`) فيختفي من المتجر ومن جدول الأسعار الذي يقبله الدفع، لكنه يبقى في جدول اللوحة مع زر «إظهار». حذف المنتج المخصّص وحده نهائي.                                                                                                                                                                                                                                                                                                                                                                |
| السعر يصل إلى الدفع                                   | `server/worker.js` يقرأ جدول الأسعار من `admin.prices()` قبل مطابقة `total`، فتعديل السعر في اللوحة يقبل الطلب بالسعر الجديد ويرفض القديم — مغطّى بفحص حقيقي في `npm run test:api`.                                                                                                                                                                                                                                                                                                                                             |
| كانت كل صفّات المنتجات تقول «لا رابط بعد»             | الربط كان في المصدر (`download: '/download/<id>'` لكل قالب) لكن التبويب المفتوح كان يحمّل **وحدات قديمة** بعد إعادة تشغيل خادم التطوير، فاختلطت النسخة القديمة بالجديدة. العمود الآن شارة «تسليم موقّع لكل طلب على حدة» لكل القوالب الخمسة عشر، و`npm run test:api` يفتح `/download/<id>` لكل منها ويتحقق أن خلفها أرشيف فعلي (١٤ حزمة تُولَّد لحظة الطلب + الرابط الذي يضيفه البائع يُمرَّر كما هو).                                                                                                                           |
| «يظهر اسم المفتاح بدل النص» (`err.stale`)             | النصّان (`err.stale` و`err.reload`) موجودان في `translations.js` للّغتين، وما يراه الزائر تُقرأ فعلًا في الفحص: `tests/entry.jsx` يركّب حدود الخطأ بحالة مُصطنعة (`qalb.test.boundary = stale                                                                                                                                                                                                                                                                                                                                   | plain`) ويتأكد أن الشاشة تعرض «إعادة تحميل الصفحة بالكامل» و«نسخة قديمة من ملفات الموقع» ولا تعرض أبدًا `err.`. ظهور اسم المفتاح يعني أن التبويب يمزج `translations.js` قديمًا مع مكوّن جديد (HMR والتبويب في الخلفية) — إعادة تحميل كاملة تُصلحه، والحالة صارت تُعالَج تلقائيًا في السطر التالي. |
| حدود الخطأ كانت تعرض «إعادة المحاولة» لصفحة لا تُصلَح | خطأ مثل `does not provide an export named …` أو `Failed to fetch dynamically imported module` ليس عطل تصيير: إعادة المحاولة تعيد استيراد نفس الوحدات المعطوبة. `src/lib/load-error.js` يميّزه، فيُعاد تحميل المستند **مرة واحدة** تلقائيًا (محميّ بـ`sessionStorage` حتى لا يدور في حلقة)، وإن بقي الخلل يظهر زرّ «إعادة تحميل الصفحة بالكامل» بدل زرّ إعادة المحاولة.                                                                                                                                                          |
| القوالب الثابتة                                       | `id` و`slug` و`type` لا تتغيّر: تغييرها يكسر روابط العملاء و`sitemap.xml` والإيصالات القديمة. المنتجات المخصّصة تُنسَل من قالب أساسي من نفس النوع.                                                                                                                                                                                                                                                                                                                                                                              |
| الحماية في وضع الخادم                                 | كلمة السر تُجزَّأ بـ scrypt + ملح (لا تُخزَّن نصًا)، الجلسة كوكي `HttpOnly` و`SameSite=Strict` أو `Bearer`، كل طلب تغيير يحتاج ترويسة `x-qalb-admin: 1`، وست محاولات فاشلة في عشر دقائق تُرجع 429 مع `retryAfter`. الملفات الناتجة بصلاحيات 0600 ومضافة إلى `.gitignore`.                                                                                                                                                                                                                                                       |
| الحماية في الوضع المحلي                               | اللوحة تشتغل بلا خادم: الحساب والتجزئة والجلسة في `localStorage`. **هذا قفل على الجهاز لا أمن حقيقي** — أي شخص يفتح أدوات المطوّر يستطيع قراءة ما في المخزن؛ للاستخدام الجاد شغّل `server/` وضع الخادم. الصفحة تقول ذلك نصًا في شارة «وضع الجهاز».                                                                                                                                                                                                                                                                              |
| محركات البحث                                          | `/admin` تحمل `robots: noindex,follow` وممنوعة في `robots.txt` وغائبةٌ عن `sitemap.xml` — فتُفتح من التذييل بلا أن تُفهرس أو تُعدّ صفحة عامة.                                                                                                                                                                                                                                                                                                                                                                                   |

```bash
# تشغيل الخادم كلوحة حقيقية (من server/README.md للتفاصيل)
ADMIN_PASSWORD='pick-a-long-one' ADMIN_EMAIL=you@qalb.store npm run api
# أو اسمح بالتهيئة من الصفحة نفسها أول مرة
ALLOW_ADMIN_SETUP=1 npm run api
```

- `npm test` يشغّل ٣٥ فحصًا على اللوحة نفسها في jsdom (بوابة، تهيئة المالك، رفض كلمة سر خاطئة،
  تعديل السعر ووصوله إلى السلة، الإخفاء ومنعه من الدفع، إضافة مسؤول، منع حذف النفس، تسجيل الخروج)،
  و`npm run test:api` يشغّل ٧٢ فحصًا على واجهة الخادم الحقيقية (الإدارة + التسليم الموقّع) (تشغّل `server/worker.js` فعلًا داخل مجلد
  بيانات مؤقت، فلا يمسّ `server/orders.jsonl` ولا `admins.json` عندك).
- القوالب التي تُنشأ من اللوحة ليست في `sitemap.xml`: القائمة تُولَّد من `src/data/templates.js`،
  فلو أردت فهرسة منتج مخصّص أضفه إلى الملف ثم `npm run gen:seo`.

## جولة لوحة الإدارة: ما صُحّح فعليًا

| ما كان                                                                       | ما صار                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `t('footer.about')` في التذييل بلا مفتاح في القاموس                          | كان يطبع `footer.about` نصًا للزائر. أُضيف المفتاح للّغتين، وأُضيف فحص `i18n · parity` يرفض أي مفتاح ناقص **أو ميت** (٥٤٥ مفتاحًا × لغتان، والاستخدام يُحتسب من النصوص المرجعية في `src/` كلّه)              |
| رابط «بطاقة هدية» يفتح قسم الباقات، و«المدونة» تفتح آراء العملاء             | تسمية تكذب على القارئ: صارت «قصص العملاء» فوق `#testimonials`، وحُذف `footer.gift` الذي لا بطاقة هدية تحته — لا وعد بلا تنفيذ                                                                                |
| ١٤٤ مفتاح إدارة كان سيدخل حزمة كل صفحة أولى                                  | نصوص اللوحة في `src/i18n/admin-strings.js` تُدمج مع chunk `/admin` وحده: المتجر 229.7 kB / 78.2 kB gzip بدل 173.8 kB / 58.2 kB قبل الفصل، واللوحة 47.5 kB لا تُحمَّل إلا عند فتحها                           |
| `save(PROD, all)` في الوضع المحلي كان يكتب منتجات اللوحة داخل ملف المستخدمين | كان يفسد الجلسة ويُبطِل «حفظ السعر» بصمت. صار `write(PROD, …)`، والفحص التفاعلي يقرأ `localStorage` ويتأكد أن `qalb.products.v1` هو من كُتب                                                                  |
| `adminLocal.js` يُحمَّل مع كل صفحات المتجر                                   | صار `import('./adminLocal.js')` ديناميكيًا خلف `adminCall`، فأنفصل في chunk مستقل (7 kB) ولا بايتات إدارة في الحزمة المشتركة                                                                                 |
| اللوحة كانت ستُعدّل `src/data/templates.js`                                  | التجاوزات طبقة فوق المصدر: الفحص يؤكد بعد الحفظ أن `templates.js` ما زال `price: 249` وأن `qalb.products.v1` يحمل 199 — فالرجوع ممكن بلا git                                                                 |
| الإيصال يَعِد بالملفات بلا رابط                                              | صار التسليم فعليًا: كل قالب له حزمة تُبنى من `src/data/deliverable.js`، وزرّ في الإيصال ينزّلها (رابط موقّع من الخادم في وضع `rest`، أو توليد داخل المتصفح في الوضع المحلي). وحيث لا ملف يقول النص ذلك صراحة |
| تلميح خطأ اللوحة يذكر بريد دعم قديمًا                                        | صياغة `admin.err.hint` بلا بريد؛ يبقى البريد الرسمي الواحد في `src/data/contact.js` (والفحص يرفض أي نسخة حرفية بعده)                                                                                         |
