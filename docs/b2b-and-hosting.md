# الجامعات، الفاحص، والاستضافة

> مستخرج من README الأصلي لتسهيل الصيانة — المصدر الوحيد للحقيقة هو الكود.

## جولة ثلاثية: مقعدٌ لكل طالب، وفاحصٌ مجاني، واستضافةٌ للقالب

**١ · من القالب إلى موقعٍ مستضاف.** اشترِ القالب فتُفتَح لك صفحة `/studio` من إيصال الطلب برابطِ تحريرٍ خاصٍّ بك: الاسم، اللون، اللغة، شبكات المعرض، ثم توليدٌ على الخادم بنفس `deliverable.js` التي تُسلَّم بها الحزمة — فلا نسخةٌ ثانية منطقَ لها. رابطُ التحرير مفتاحٌ من ثمانية عشر حرفًا لا كلمة سر: يُصدَّر من `/host` ويُخبَّأ في المتجر ولا يظهر في أيّ CSV إداري. الخطة المجانية تُعلِّم الموقع بشعارنا وتحصي عشرَ عمليات تحرير في الشهر؛ وPro (٥٠٠ ريال شهريًا) يُسقط الشعار ويفتح النطاق الخاص والتوليد بلا حدّ وتصدير ملفات المصدر — بسقف ثلاثة قوالب في الشهر — وترقيةُ الخطة عندنا يدُ موظفٍ لا زرٌّ في الشاشة، لأن خلفها دفعًا حقيقيًا. الأرقام كلها تُقرأ من `PLANS`/`HOST_LIMITS` ولا تُكتب مجددًا في الواجهة.

**٢ · فاحص ATS مجاني على `/ats`.** يلصق الزائر نصَّ سيرته (أو يختار `.txt`/`.md`) فتُقيَس في المتصفح سبعةُ شروط: ملخّص، عنوان خبرة معروف، مهارات مستقلّة، تعليم، بريدٌ يُقرأ، تواريخٌ على نسقٍ ثابت، ورصاصاتٌ نصفُها يحمل رقمًا — مع طولٍ بين ٣٢٠ و٩٠٠ كلمة. النطاقات (٧٠ للنجاح، وأقلّ من ٤٠ كلمة لا تُقاس أصلًا) من `ATS_TARGET`، والجدولُ نفسُه `src/data/ats-table.js` يقرأه الفاحص، وشارةُ القالب في المتجر، وسكربت `scripts/check-ats.mjs` المولَّد **داخل كل حزمة CV** من `src/data/ats.js` (لا ملفَّ بهذا الاسم في مستودع `scripts/`). لا `fetch` ولا `localStorage` في مسار التحليل: يثبّت الفحص أن الملف لا يغادر التبويب، وأن PDF مرفوضٌ صراحةً لا بقائمةِ أعذار.

**٣ · تراخيص سنوية للمعاهد على `/b2b`.** خمسُ باقات (٢٥/٥٠/١٥٠/٣٠٠/٥٠٠ مقعد مقابل ٣٩٠٠/١٥٠٠٠/٢٤٠٠٠/٣٣٠٠٠/٤٥٠٠٠ ريالًا في السنة)؛ أصغرُها فصلٌ تجريبيٌّ بـ٢٥ مقعدًا يُعقَد تحت توقيع العميد، وائتمانُه يُخصَم عند الترقية بخطوةٍ من الموظف (لا بوابة دفع بعد). سعرُ المقعد لا يُقارَن بأرخص قالب: `seatBundle()` يرجّع المرجعَ من الكتالوج نفسه (٤٤٩ ريالًا لقالبٍ يحمل سيرةً ذاتية) فتُطبع النسبُ محسوبةً (٣٣–٨٠٪ تحت الفردية) وتُطبع التجزئةُ نطاقًا ٥٩–٤٤٩ معدودًا من السبعة القابلة للقياس (`seatRetailBand()`). ما يُكتب في الاستمارة يصلُ ثلاثةَ أماكن من مصدرٍ واحد: `POST /leads` إلى `server/leads.json` (٠٦٠٠ · رقمُ عرضٍ `QALB-Q-…` · ضريبةٌ مفصولة · صلاحيةُ ثلاثين يومًا)، وورقةُ عرضِ سعرٍ تُطبع PDF وحدها بفضل `[data-no-print]`، وبريدٌ مسطورٌ إلى `qalb@qalb.store`. وفي الوضع المحلي دفترُ المتصفح `qalb.leads.v1` مع تنويهٍ صريح أنه لا يُرى عندنا، وتصديرٍ ومسحٍ حقيقيَّين. الهاتفُ وموعدُ العرضِ وهويةُ المنشأة كلها من `VITE_QALB_*`: ما لم يُضبط لا يظهر — فلا زرَّ «اتصل» بلا رقم، ولا «قيدَ التوثيق» يُغطَّى برقمٍ مُختلَق. والفاحصُ نفسه صار أداةَ قياس: تُلصق سِيَرُ الدفعة مفصولةً بـ`---` فتحصل متوسطًا وعددَ العابرين حدَّ ٦٠ وتصديرَ نتائجِ لا نصٍّ معهما. يُصدر الموظف رمزًا بالأسلوب `QALB-XXXX-XXXX` من لوحة الإدارة، فيستهلك الطالبُ مقعدًا بـ`POST /org/redeem` فيُنشَأ طلبٌ حقيقي بـ`total = 0` و`discount = 89` ومفتاحُ ترخيصٍ كأيّ مشتَرٍ — فيفتح `/download/<template>?order=&key=` ويحصل على نفس الحزمة المولَّدة باسمه. بريدُ الجهة وحده يخرج في التصدير، مع عدِّ المقاعد لكل قالب (`byTemplate`) والائتمانُ المطبَّق (`credit`) محسوبَين من الدفتر وقت القراءة — فلا «تقرير نهاية السنة» يُعاد عدّه يدويًا ولا رقمٌ فيه يُختلَق.

## ما الجديد في هذه النسخة (بعد تغيير الفكرة)

|                       |                                                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **٢٠ منتجًا**         | ٨ مواقع بورتفوليو (تصميم، تصوير، برمجة، موشن، كتابة، ثلاثي الأبعاد، استوديو، بسيط) + ٦ سير ذاتية + ٤ حزم موقع+سير + حزمة LinkedIn + قوالب خطابات |
| **معاينة الموقع حية** | `SitePreview` يرسم موقعًا كاملًا داخل إطار متصفح: شريط علوي، ترويسة (٣ أنماط)، شبكة أعمال (٤ أنماط)، تذييل — وكل ذلك HTML/CSS بدون أي صورة       |
| **تبديل الشاشات**     | سطح مكتب / لوحي / جوال — يُعاد حساب مقياس التصميم فعليًا لكل مقاس                                                                                |
| **تبديل الحزمة**      | في منتجات الحزمة زر يبدّل بين «الموقع» و«السيرة» بنفس الألوان والخط                                                                              |
| **مقاييس مزدوجة**     | درجة أداء (Lighthouse-style) للمواقع + درجة ATS للسير، وتظهران معًا في الحزم                                                                     |
| **قسم نشر**           | أوامر `git clone → npm i → vercel deploy` مع زر نسخ يعمل فعلًا عبر Clipboard API                                                                 |
| **بحث أذكى**          | فهرس البحث يشمل التقنيات، الأقسام، المهارات، سمات المشاريع، والأدوار — فتح «Kubernetes» يعثر على أطلس                                            |
| **هوية واحدة**        | قسم `Identity` يعرض الموقع والسيرة جنبًا إلى جنب مع لوحة الألوان المشتركة                                                                        |

## تشذيب هذه الجولة (إصلاحات لا تجميل)

| المشكلة                               | الحل                                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| حزمة واحدة 401 kB لكل المسارات        | `React.lazy` لكل مسار + `<Suspense>` بهيكل تحميل — الأصلي 308 kB وبقية الصفحات 13 حزمة صغيرة                  |
| المعاينة تختفي في حاوية بعرض 0        | `scale = w ? w/dev.w : 1` بدل هيكل تحميل أبدي — المحتوى موجود دائمًا في DOM                                   |
| معاينة المواقع كانت `dir="ltr"` دائمة | `Site()` تستقبل `rtl` وتضبط `dir` (مع عزل اتجاه رابط الموقع)                                                  |
| Enter لا ينقل بين خطوات الدفع         | الخطوة `<form onSubmit>` وزر «متابعة» `type="submit"` + `inputMode/enterKeyHint/autoComplete` للبطاقة والجوال |
| أخطاء الحقول بلا ربط                  | `aria-invalid` + `aria-describedby` + `role="alert"` (الدفع وكود الخصم)                                       |
| مفتاح الترخيص يقول «تم النسخ» دائمًا  | Clipboard API مكشوف الفشل: رسالة صريحة عند المنع + تنزيل ملف `.txt`                                           |
| نافذة المعاينة تسرّب التركيز          | `createPortal` إلى `body` + `inert`/`aria-hidden` على `#root` + مصيدة Tab واسترجاع التركيز                    |
| «شاهدتها مؤخرًا» معرّفة وغير مستخدمة  | `pushRecent` يُنادى من صفحة المنتج، والشريط يظهر في الرئيسية والكتالوج                                        |
| عنوان/وصف ثابت لكل المسارات           | `Seo.jsx` يحدّث `title` و`description` و`og:`/`twitter:` لكل مسار                                             |
| ToastAdd خاطئ تحت StrictMode          | `add()` يقرأ `lines` مباشرة ويعيد هل العنصر جديد                                                              |
| نصوص منسوخة في الكود                  | `cart.couponRemoved` · `success.copyFail` · `wishlist.count` · `featured.recent*`                             |
| `Btn` داخل `<form>` يرسل النموذج      | `type="button"` افتراضيًا عند عدم وجود `to`                                                                   |
